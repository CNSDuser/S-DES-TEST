# S-DES 用户指南

## 快速开始

### 1. 环境准备
- 确保已安装Java 8或更高版本
- 下载所有源代码文件到同一目录

### 2. 编译程序
```bash
javac *.java
```

### 3. 运行程序
```bash
# 基础GUI（第1-2关）
java SDESGUI

# 高级GUI（第3-5关）
java SDESAdvancedGUI

# 控制台测试
java SDESTest
```

## 详细使用说明

### 基础GUI界面（SDESGUI）

#### 界面说明
- **10位密钥 K**：输入10位二进制密钥（仅0和1）
- **8位明文 P**：输入8位二进制明文（仅0和1）
- **8位密文 C**：显示8位二进制密文（只读）
- **日志区域**：显示操作记录和结果

#### 操作步骤
1. 在"10位密钥 K"字段输入密钥，如：`1010000010`
2. 在"8位明文 P"字段输入明文，如：`10111101`
3. 点击"加密"按钮
4. 查看"8位密文 C"字段的加密结果
5. 查看下方日志区域的详细记录

#### 解密操作
1. 确保"8位密文 C"字段有密文数据
2. 点击"解密"按钮
3. 明文将显示在"8位明文 P"字段

### 高级GUI界面（SDESAdvancedGUI）

#### 第3关：字符串加解密

**功能**：支持ASCII字符串的加解密，输出HEX格式密文

**操作步骤**：
1. 切换到"第3关：字符串加解密"标签
2. 输入10位二进制密钥
3. 在"明文 (ASCII)"区域输入文本，如：`HELLO`
4. 点击"加密"按钮
5. 查看"密文 (HEX)"区域的十六进制结果
6. 点击"解密"可还原原文

**支持格式**：
- 英文字母：A-Z, a-z
- 数字：0-9
- 符号：!@#$%^&*()等
- 空格和换行

#### 第4关：暴力破解

**功能**：通过穷举所有1024个密钥来破解明密文对

**操作步骤**：
1. 切换到"第4关：暴力破解"标签
2. 输入10位二进制密钥
3. 在"明文"区域输入数据（支持二进制或ASCII）
4. 点击"生成测试数据"生成对应的密文
5. 点击"暴力破解"开始穷举
6. 查看进度条和结果区域

**输入格式**：
- 二进制：8位0/1字符串，如`10111101`
- ASCII：任意文本，如`HELLO`

**结果说明**：
- 单对破解：通常找到4-8个候选密钥
- 多对破解：通常只找到1个真实密钥
- 显示破解用时和候选密钥列表

#### 第5关：统计分析

**功能**：分析密钥碰撞现象和密文分布

**操作步骤**：
1. 切换到"第5关：统计分析"标签
2. 点击"开始统计分析"按钮
3. 等待分析完成
4. 查看详细的分析结果

**分析内容**：
- 密钥碰撞统计
- 密文-密钥映射关系
- 具体碰撞例子
- 算法安全性评估

## 常见问题解答

### Q1：为什么输入密钥时提示"输入错误"？
**A**：密钥必须是正好10位的二进制字符串，只包含0和1。例如：`1010000010`

### Q2：为什么明文输入被拒绝？
**A**：在基础GUI中，明文必须是8位二进制字符串。在高级GUI的字符串模式中，可以输入任意ASCII文本。

### Q3：暴力破解需要多长时间？
**A**：通常10-30毫秒，具体取决于计算机性能。多线程处理会显著提升速度。

### Q4：为什么暴力破解找到多个密钥？
**A**：这是正常现象。由于密钥空间(1024)大于密文空间(256)，平均每个密文对应4个密钥。使用多个明密文对可以减少误报。

### Q5：如何验证结果的正确性？
**A**：
1. 使用相同的密钥和明文多次加密，结果应该一致
2. 加密后立即解密，应该得到原始明文
3. 与其他组同学交换测试用例进行交叉验证

### Q6：程序运行缓慢怎么办？
**A**：
1. 确保使用Java 8或更高版本
2. 关闭其他占用内存的程序
3. 对于大量数据，建议分批处理

## 错误处理

### 常见错误及解决方案

| 错误信息 | 原因 | 解决方案 |
|---------|------|----------|
| "密钥K 必须是长度为 10 的二进制串" | 密钥格式错误 | 输入10位0/1字符串 |
| "明文P 必须是长度为 8 的二进制串" | 明文格式错误 | 输入8位0/1字符串 |
| "HEX长度必须为偶数" | HEX格式错误 | 确保HEX字符串长度为偶数 |
| "非法HEX字符" | HEX包含非十六进制字符 | 只使用0-9, A-F字符 |
| "明密文对数量不一致" | 数组长度不匹配 | 确保明文和密文数组长度相同 |

## 性能优化建议

### 1. 硬件要求
- **CPU**：双核以上推荐
- **内存**：至少2GB可用内存
- **存储**：至少100MB可用空间

### 2. 软件优化
- 使用最新版本的Java运行时
- 关闭不必要的后台程序
- 定期清理系统缓存

### 3. 使用技巧
- 对于大量数据，建议使用批量处理
- 暴力破解时避免同时运行其他计算密集型程序
- 统计分析可能需要较长时间，请耐心等待
