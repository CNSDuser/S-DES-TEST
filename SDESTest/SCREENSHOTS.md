## 如何获取截图

### 1. 运行程序
```bash
javac *.java
java SDESGUI          # 基础GUI
java SDESAdvancedGUI  # 高级GUI
```

### 2. 执行测试用例
按照各关卡要求输入测试数据，执行相应功能。

### 3. 截取屏幕
- Windows：使用Snipping Tool或Win+Shift+S
- Mac：使用Cmd+Shift+4
- Linux：使用gnome-screenshot

### 4. 保存截图
将截图保存到项目根目录，按照命名规范重命名。
